# IIIT-H-Summer-School-2026

This repository contains my implementations and learning notes from the
Summer School 2026 program.

The notebooks provided in the program were used as the starting point.
My work primarily focuses on understanding the concepts, reproducing the
implementations, experimenting with the provided code, and documenting
the observations and results.

## Objectives

- Understand the concepts introduced in each session.
- Implement and execute the provided notebooks.
- Study the underlying machine learning/deep learning techniques.
- Experiment with different parameters and configurations.
- Analyze model outputs and results.
- Build an understanding of the complete workflow rather than treating
  the notebooks as black-box implementations.

## Approach

The notebooks were provided as part of the Summer School program. My
contribution is focused on implementation, experimentation, and
understanding of the concepts demonstrated in them.

For each notebook, I:
1. Studied the theoretical concept.
2. Walked through the provided implementation.
3. Executed the notebook and analyzed the outputs.
4. Investigated important parameters and design choices.
5. Performed modifications/experiments where applicable.
6. Documented my observations and understanding.
